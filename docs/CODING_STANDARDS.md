# Conclik Coding Standards

Version: 1.0
Status: Foundation

---

# Rule 1

One file

One responsibility.

---

# Rule 2

Every module must have
a version header.

---

# Rule 3

Every public class
must include documentation.

---

# Rule 4

No duplicated code.

---

# Rule 5

Security before functionality.

---

# Rule 6

Every important module
must pass syntax validation.

---

# Rule 7

Every security module
must include tests.

---

# Rule 8

Meaningful names only.

Avoid:

a.py

test1.py

new.py

Use:

security_manager.py

provider_manager.py

workflow_engine.py

---

# Rule 9

Commit frequently.

Every stable milestone
must be committed to Git.

---

# Rule 10

Never break the Foundation.

Backward compatibility
must always be considered.
